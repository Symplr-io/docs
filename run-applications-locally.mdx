Run Application Locally allows the generated application to be executed within a local development environment for continued development, testing, customization, and validation outside the Symplr platform.

After downloading the generated application package, Symplr provides all required project files, configuration assets, and setup instructions needed to run the application locally.

The local development environment allows the application to be validated, extended, tested, and prepared for deployment outside the Symplr platform.

## Before You Begin

Before running the application locally, ensure:

- The application code package has been downloaded successfully
- The downloaded package has been extracted locally
- Access to the project README file is available
- An Android Emulator or iOS Simulator is available
- The local development environment is ready for setup

## Download and Extract the Application Package

Begin by downloading the generated application package from Symplr.

<Frame>
  ![1 Downloaded Code Package](/images/1-downloaded-code-package.jpg)
</Frame>

After the download completes, extract the package to a local directory.

<Frame>
  ![2 Extracted Project Folder](/images/2-extracted-project-folder.jpg)
</Frame>

The extracted project folder contains the application source code, configuration files, generated test resources, and supporting project assets.

## Review the Project README File

Open the extracted project folder and locate the **README** file.

<Frame>
  ![3 README File](/images/3-readme-file.jpg)
</Frame>

The README file contains the setup instructions required to configure the local development environment and run the application.

The README includes setup guidance for Android and iOS environments, dependency installation, application execution, and generated test cases.

Following the README instructions ensures that all required prerequisites and project dependencies are configured correctly before running the application.

## Install Project Dependencies

After reviewing the README instructions, install the required project dependencies.

<Frame>
  ![4 Install Dependencies](/images/4-install-dependencies.jpg)
</Frame>

Dependency installation prepares the project and supporting libraries required for local execution.

Once installation completes successfully, the application is ready to be launched within the local development environment.

## Run the Application

After completing the setup and installation steps, follow the README instructions to launch the application using an Android Emulator or iOS Simulator.

<Frame>
  ![5 Running Application in Android Emulator](/images/5-running-application-in-android-dev.jpg)
</Frame>

The local execution process starts the generated application and makes it available for development, testing, and validation activities.

## Validate the Running Application

Once the application launches successfully, the generated application becomes available within the emulator or simulator environment.

<Frame>
  ![6 Application Running Locally](/images/6-application-running-locally.jpg)
</Frame>

The running application can be used to validate:

- Screen layouts
- Navigation flows
- Forms and interactions
- Workflow behavior
- Overall application functionality

This validation process helps confirm that the generated application is functioning as expected within the local environment.

## Execute Generated Test Cases

If test resources were included during code generation, the project also contains generated test assets.

Follow the test execution instructions provided in the README file to run the generated test cases.

<Frame>
  ![7 Test Execution](/images/7-test-execution.jpg)
</Frame>

Generated test cases help validate application functionality and identify potential issues before deployment.

The test execution process verifies application behavior against the generated test scenarios.

## Review Test Results

After test execution completes successfully, review the generated test reports and execution results.

<Frame>
  ![8 Test Report](/images/8-test-report.jpg)
</Frame>

Test reports provide visibility into executed test cases, validation results, and any issues identified during testing.

These reports help support troubleshooting, quality validation, and deployment readiness activities.

## Next Steps

After successfully running the application locally, continue by extending application functionality, integrating external services, validating generated test cases, configuring deployment environments, or preparing the application for release.
